# 🌴 Nusantara Guide Belitung

Nusantara Guide Belitung adalah aplikasi mobile berbasis Flutter yang dirancang sebagai media digital interaktif untuk memperkenalkan destinasi wisata unggulan di Kabupaten Belitung. Aplikasi ini menyediakan informasi wisata, artikel edukatif, serta kuis interaktif untuk meningkatkan pengetahuan pengguna mengenai objek wisata daerah.

## 📖 Tentang Aplikasi

Belitung merupakan salah satu destinasi wisata terkenal di Indonesia yang memiliki keindahan alam, pantai berpasir putih, batu granit unik, serta berbagai lokasi wisata bersejarah dan edukatif. Melalui aplikasi ini, pengguna dapat menjelajahi berbagai informasi wisata secara mudah, menarik, dan interaktif.

## 🚀 Cara Menjalankan Project

### Clone Repository

```bash
git clone https://github.com/username/nusantara-guide-belitung.git
```

### Masuk ke Folder Project

```bash
cd nusantara-guide-belitung
```

### Install Dependency

```bash
flutter pub get
```

### Jalankan Aplikasi

```bash
flutter run
```
